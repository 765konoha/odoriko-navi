# 踊り子ナビ(odoriko-navi)

よさこい祭り等に参加する踊り子が、祭り当日に「次に何時・どこへ行けばよいか」をスマートフォンからすぐ確認できる Web アプリ。

- 設計書: [docs/DESIGN.md](docs/DESIGN.md)
- スタック: React 19 / TypeScript / Vite / Tailwind CSS v4 / React Router v7(HashRouter)/ Leaflet / Supabase / GitHub Pages

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```
